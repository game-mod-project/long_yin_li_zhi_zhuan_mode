## 1. spike 확정 — GameController generator 실제 시그니처 (인게임 진단 F11+9)

CT 테이블의 후보값과 **다른 점**이 있어 spike 가 결정적이었음. CT 는 ASM 레지스터 순서로 호출하므로 C# 시그니처와 달랐고, **모든 `bossLv` 가 `Single`(float)** 라 int 를 넘기면 `MissingMethodException` (IsAssignableFrom(Single,int)=false).

| 카테고리 | 확정 시그니처 (GameController 인스턴스 메서드) |
|---|---|
| 무기 | `ItemData GenerateWeapon(int itemLv, int weaponID, Single bossLv, HeroData targetHero)` (4-arg, weaponID=특정) |
| 갑옷 | `ItemData GenerateArmor(int itemLv, int littleType, Single bossLv, HeroData targetHero)` |
| 투구 | `ItemData GenerateHelmet(int itemLv, int littleType, Single bossLv, HeroData targetHero)` |
| 신발 | `ItemData GenerateShoes(int itemLv, int littleType, Single bossLv, HeroData targetHero)` |
| 장신구 | `ItemData GenerateDecoration(int itemLv, int littleType, Single bossLv, HeroData targetHero)` |
| 마구 | `ItemData GenerateHorseArmorData(int lv, Single bossLv)` (player 없음) |
| 단약 | `ItemData GenerateMedData(int id, Single bossLv)` |
| 음식 | `ItemData GenerateFoodData(int id, Single bossLv)` |
| 재료 | `ItemData GenerateMaterial(int materialType, int itemLv, Single bossLv)` (3-arg) |
| 말 | `ItemData GenerateHorseData(int id, Single bossLv)` |
| 보물 | `ItemData GenerateTreasure(int treasureType, int itemLv, Single bossLv)` (3-arg) |
| 비급 | `ItemData GenerateBook(int skillLv, Single bossLv, int forceID, Random randomTarget)` — **특정 스킬 지정 불가** → `GenerateBook` 으로 Book ItemData 얻은 뒤 `ItemData.SetBookData(skillID, rareLv)` override |

**중요 사실:**
- **rareLv(품질) 를 받는 generator 없음** → 생성 후 reflection 으로 `item.rareLv` set + `CountValueAndWeight`.
- **itemLv(등급) 를 안 받는 카테고리** (단약/음식/말) → 생성 후 `item.itemLv` post-set.
- **GameController 인스턴스** = `GameController.Instance` (HeroLocator 패턴으로 접근).

### 1.1 GameDataController DB property (확정 — F11+9 진단)
존재: `weaponDataBase, armorDataBase, helmetDataBase, shoesDataBase, medDataBase, foodDataBase, horseDataBase, kungfuSkillDataBase` (+ force/area/building/hero 등 다수).
**부재**: `decorationDataBase, materialDataBase, treasureDataBase` — 이 3종은 DB 가 아니라 **type 인덱스 생성**.
- 장신구 = littleType 0~5 (향낭/옥선/반지/옥패/요대/면구) — 합성 entry
- 마구 = 단일 (안구) — 합성 entry
- 재료 = materialType 0~3 (목재/광석/약재/식재) — 합성 entry
- 보물 = treasureType 개수 미상 → **런타임 probe**(GenerateTreasure 호출 후 name 읽기, 3회 연속 실패 시 중단)로 자동 발견

`ItemDbCache: built 1170 entries`, `SkillNameCache: built 996 entries` (비급 996 + 장비/소비 174).

## 3. 최종 구현 자산 (v0.7.13)

- `GameControllerLocator` — `GameController.Instance` reflection (HeroLocator mirror).
- `ItemGenCategory` / `ItemGenCategoryNames` — 7 카테고리 enum + 한글.
- `GeneratorSpec` — 카테고리/subType → 메서드명 매핑.
- `ItemGenEntry` / `ItemGenFilter` — DB entry POCO + 순수 필터/페이징.
- `ItemDbCache` — 7 DB 열거 + 비급 SkillNameCache 위임 + 장식품/마구/재료 합성 + 보물 probe.
- `ItemFactory` — generator reflection 호출 (bossLv float) + Book SetBookData + itemLv/rareLv post-set + FinalizeNewItemWrapper + GetItem.
- `ItemGeneratorPanel` (F11+5) — 카테고리/secondary 탭 + 검색 + 페이징(10/15/20) + 등급/품질 선택형 + 수량 + 생성. 선택은 entry 참조 (전체 탭 정확).

테스트: 416 (GeneratorSpec 4 + ItemGenFilter 5 + ItemFactoryArg 4 + ItemDbCache 1 신규).

## 4. 알려진 한계 / 후속 (v0.7.14+)
- 갑옷/투구/신발 = DB index 를 littleType 으로 넘김 (smoke 상 "종류 일치"). 재료/보물 = type 단위 (특정 개별 아이템 아님 — API 한계).
- 비급 SetBookData 시그니처는 flexible invoke (있으면 특정 스킬, 없으면 random book fallback) — smoke 상 정상.
- **v0.7.14 이벤트 생성** (WorldEventController.CreateWorldEvent) — 사용자 요청, 별도 sub-project.
